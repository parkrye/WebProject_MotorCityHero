# 모터시티 히어로 : 미스터 D

고전 오락실 스타일 횡스크롤 배틀 액션. 바닐라 HTML5 Canvas + JavaScript, 빌드 도구 없음.

## 실행

**`run-game.bat` 을 더블클릭**하면 로컬 서버가 뜨고 브라우저가 열립니다.
같은 공유기에 물린 폰·노트북에서도 콘솔에 찍힌 `http://<이 PC 의 IP>:47823` 로 접속할 수 있습니다.

```
====================================================
  모터시티 히어로 : 미스터 D
====================================================
  이 PC      http://localhost:47823
  다른 기기  http://192.168.0.12:47823
----------------------------------------------------
  종료: Ctrl+C
====================================================
```

- 포트는 **47823** 입니다. IANA 미할당이고 Windows 임시 포트 범위(49152~) 밖이라 충돌이 잘 나지
  않습니다. 이미 점유 중이면 47824, 47825… 로 알아서 옮겨가고 옮긴 포트를 알려줍니다.
- 첫 실행 때 방화벽 인바운드 허용 규칙(`MotorCityHero LAN`, TCP 47823, **개인 네트워크 한정**)이
  없으면 관리자 권한 창이 한 번 뜹니다. [예] 를 눌러야 다른 기기에서 접속됩니다.
  거부해도 서버는 그대로 뜨고, 이 PC 에서는 정상적으로 플레이할 수 있습니다.
- 캐시를 끄고 서빙하므로 에셋을 교체한 뒤에는 새로고침만 하면 반영됩니다.

옵션은 `run-game.bat` 뒤에 그대로 붙이면 됩니다.

| 옵션 | 동작 |
|---|---|
| `--port 50000` | 포트 지정 |
| `--local-only` | `127.0.0.1` 에만 바인딩. 외부에 열지 않음 (방화벽도 건드리지 않음) |
| `--no-browser` | 브라우저 자동 실행 안 함 |
| `--no-firewall` | 방화벽 규칙을 확인·등록하지 않음 |
| `--close-firewall` | 등록해둔 방화벽 규칙을 제거하고 종료 |

`index.html` 을 `file://` 로 바로 열어도 동작합니다. 다만 이 경우 다른 기기에서는 접속할 수 없습니다.

서버 본체는 `tools/serve.py` 이고 표준 라이브러리만 씁니다. Python 3 만 있으면 됩니다.

```bash
python tools/serve.py --local-only   # macOS · Linux 에서도 동일하게 동작 (방화벽 처리는 Windows 전용)
```

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 상하좌우 이동 |
| `J` | 공격 |
| `P` | 코인 투입 (오락실 흉내. 눌러서 코인 1개 획득) |
| `R` | 게임오버 후 재시작 |

모든 스프라이트는 오른쪽이 정방향이며, 왼쪽을 볼 때만 `ctx.scale(-1, 1)` 로 좌우 반전해서 그립니다.
위/아래만 입력했을 때는 보던 방향을 유지합니다.

## 게임 플로우

```
INTRO      화면 좌측 밖에서 가로 1/3 지점까지 자동 이동 (조작 불가) + 타이틀
COUNTDOWN  3 → 2 → 1 → START
PLAYING    enemy_1 부터 등장. 격파 시 점수 획득, 누적 점수가 임계값을 넘으면 다음 레벨 해금
CONTINUE   생명 0. 코인이 있으면 즉시, 없으면 10초 카운트다운 동안 코인을 기다린다
FADEOUT    컨티뉴 실패. 암전
GAMEOVER   R 로 재시작
```

- 스테이지는 배경을 가로 3타일 반복해 만든 폭 3072 월드이며, 카메라가 플레이어를 따라 좌→우로 흐릅니다.
- 상하 이동은 도로 영역으로 제한되고, 안쪽(위)일수록 캐릭터가 작게 그려집니다 (벨트스크롤 원근).
- 발끝 y 기준으로 정렬해 앞뒤 겹침을 처리합니다.

### 생명 · 코인 · 회복

- 생명 3개로 시작. **무엇에 맞든 한 대 = 생명 1** 이고, hit 애니메이션이 도는 동안(560ms)은 무적이다.
- 생명이 0이 되면
  - 코인이 있으면 1개를 쓰고 **점수와 레벨을 유지한 채** 생명 3개로 그 자리에서 이어간다 (적은 정리되고 잠깐 무적).
  - 코인이 없으면 10초 카운트다운. 그 사이 `P` 로 코인이 들어오면 똑같이 이어서 시작한다.
  - 카운트다운이 끝나면 암전 후 GAME OVER.
- 적을 쓰러뜨리면 5% 확률로 회복 아이템이 떨어진다. 접촉하면 생명 +1 (한도 없음).
- 생명이 10개를 넘으면 HUD 가 아이콘 나열 대신 `♥ X 12` 로 축약한다.

### 레벨 진행

| 레벨 | 에너미 | 해금 점수 | 격파 점수 | 필요 타격 수 |
|---|---|---|---|---|
| 1 | enemy_1 | 0 | 100 | 1 |
| 2 | enemy_2 | 600 | 220 | 2 |
| 3 | enemy_3 | 1,600 | 380 | 3 |
| 4 | enemy_4 | 3,200 | 600 | 4 |
| 5 | enemy_5 | 5,600 | 900 | 5 |
| 6 | enemy_6 | 9,000 | 1,400 | 6 |

레벨이 오르면 등장 간격이 짧아지고 동시 등장 수가 늘어납니다. 현재 레벨 위주로 뽑되 가끔 한 단계 아래도 섞입니다.

## 구조

```
run-game.bat         서버 실행 런처 (Python 탐색 → tools/serve.py)

js/bitmapfont.js     비트맵 폰트 렌더러 (A-Z, 0-9)
js/entity.js         Actor 공통 (좌표 · 넉백 · 원근 배율)
js/assets.js         이미지 로더

js/enemy.js          추격 → 준비동작 → 타격 → 쿨다운 AI
js/pickup.js         회복 아이템 (튀어오름 → 착지 → 소멸)
js/spawner.js        점수 기반 레벨 해금 · 스폰
js/hud.js            생명 · 코인 · 점수 · 컨티뉴 · 암전 · 게임오버

assets/              변환된 스프라이트시트 + sprites.js
```

밸런스를 바꾸려면 `js/config.js` 만 보면 됩니다.

## 에셋 교체

원본은 256x256 / 8프레임 / 투명 배경 GIF 입니다. canvas 의 `drawImage` 는 애니메이션 GIF 의
프레임을 제어할 수 없으므로, 가로로 이어붙인 스프라이트시트 PNG 로 미리 변환해서 씁니다.

원본 폴더 구조:

```
<원본>/player_idle.gif  player_walk.gif  player_attack.gif  player_hit.gif
<원본>/game_bg.png
<원본>/enemy/enemy_1.gif ... enemy_6.gif
<원본>/sprites/heartIcon.png  coin.png  healItem.png  font.png
```

변환:

```bash
python tools/build_sprites.py <원본_에셋_폴더>
```

`assets/` 에 시트 PNG 와 `sprites.js`(`window.SPRITE_MANIFEST`)가 생성됩니다.
`file://` 에서는 `fetch` 로 JSON 을 읽을 수 없어 매니페스트를 JS 전역으로도 굽습니다.

한 캐릭터의 모든 애니메이션은 **공통 x 범위로 크롭**되고 세로 256 을 그대로 유지합니다.
그래야 애니메이션이 바뀌어도 캐릭터가 떨리지 않고, 발끝이 항상 바닥에 정렬됩니다.

### 폰트

`font.png` 는 A-Z / 0-9 가 6x6 으로 배치된 시트입니다. 칸 폭이 균일하지 않아 6등분으로는
정확히 잘리지 않으므로, 알파가 비어있는 구간을 찾아 행·열 밴드를 검출한 뒤 글리프마다 다시
타이트하게 자릅니다. 모든 글리프가 칸 위쪽에 정렬되어 있어 위 기준으로 맞추면 베이스라인이 맞습니다.

**폰트에 없는 글자는 그려지지 않습니다.** 그래서 게임 내 문구는 전부 영문 대문자이고,
하이픈·콜론이 없어 `HI-SCORE` 대신 `HI SCORE` 처럼 공백을 씁니다. 문구를 바꿀 때 주의하세요.
